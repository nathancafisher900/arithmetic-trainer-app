## About the Project

Arithmetic Trainer provides a web-based environment for working on arithmetic and general mathematics. Physics exercises are included as well, allowing several related technical subjects to be practiced through one compact educational tool.

It is designed for learners who need an accessible way to review calculations, build confidence with mathematical problems, or complete physics exercises online. Because it runs in the browser, no separate desktop application is required.
